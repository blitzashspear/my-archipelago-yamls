Hello, and congratulations! You have found my YAML repository for [Archipelago](https://archipelago.gg/). If you don't know what YAMLs are and how they relate to Archipelago, too fuckin bad I'm not giving you a lecture.

Here's what each folder means.\
ASYNC: Games with settings that are only possible over the course of multiple days in an asynchronous setting.\
MANUAL: Games that use [The Manual Client](https://github.com/ManualForArchipelago).\
SIDE: Games that can be completed quicky, usually within 30-60 minutes.\
SYNC: Games that have settings adjusted to be completed in about 3-5 hours.\
UNTESTED: Games that have settings I want to test first, or I simply haven't played the APWorld at all.\
WAITING: Games that I submitted to an async so I can test them.\
